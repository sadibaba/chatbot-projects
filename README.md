# chatbot-projects

My chatbot experiments: from simple FAQ bots to AI assistants, built with Node.js and Express.

# Chatbot Projects

I'm learning how chatbots work by building them one by one, starting simple and getting a bit harder each time. I use Node.js, Express and the DeepSeek API.

## Projects

| #   | Project                    | What it does                                                                        |
| --- | -------------------------- | ----------------------------------------------------------------------------------- |
| 1   | FAQ Bot                    | Answers common questions using fixed rules, no AI involved.                         |
| 2   | Memory Bot                 | A chat with AI that remembers what you said earlier in the conversation.            |
| 3   | Context Bot                | Answers questions from my own documents by adding them to the prompt.               |
| 4   | Booking Bot                | Books an appointment by calling my own API when the user asks.                      |
| 5   | Intake Form                | A simple digital form that saves patient-style details to a database.               |
| 6   | Reminder Bot               | Sends a reminder email before an appointment.                                       |
| 7   | Handoff Bot                | Passes the chat to a human when the bot can't answer.                               |
| 8   | Admin Dashboard            | Shows bookings and chat stats in one place.                                         |
| 9   | Chatbot with human handoff | If the bot fails to understand, it will transfer the conversation to a staff member |
| 10  | Mini healthcare portal     | login, appointments, messages, HIPAA-aware logs                                     |

## Notes

- All data in these projects is fake. I never use real personal information.
